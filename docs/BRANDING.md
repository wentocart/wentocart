# Branding

The product name is **WentoCart**.

Shoppers still see the shop title from Shop information (`APP_NAME` on a new install). That title can differ from the product name.

| Use | Value |
| --- | --- |
| Product name | `WentoCart` |
| Zip names and composer package | `wentocart` |
| Composer package | `wentocart/wentocart` |
| Demo admin on a fresh install | `admin@wentocart.test` |
| GitHub repository | `wentocart/wentocart` — this is the repository path, not the product name |

Use **WentoCart** in new copy, seeds, and installer defaults.
