# Changelog

Notable changes to WentoCart are recorded here.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Version numbers follow [Semantic Versioning](https://semver.org/).

## [1.0.0] — 2026-11-04

First public source release.

### Added

- Storefront with the Classic theme: home, catalog, product pages, cart, checkout, and order confirmation
- Customer account: sign in, register, password reset, orders, profile, addresses, reviews, and help
- Admin back office for catalog, orders, customers, design, and settings
- Seller marketplace (customers apply; approved sellers use a storefront dashboard)
- Browser wizard and CLI installer (`php artisan wento:install`)
- Bundled Main Menu extension
- Extension marketplace catalog (other modules install from the store, not this repository)
- Upgrade, backup, restore, and `/wento-recovery.php` for live shops
- Languages, translations, and a currency switcher
