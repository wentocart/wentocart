# Main menu

Official WentoCart extension for the storefront’s primary navigation.

## Features

- Compose the header menu from **categories**, **CMS pages**, and **custom links**
- Drag-style ordering, enable/disable per item, and optional **open in new tab**
- Multilingual labels for custom links
- Nested category trees resolved when the menu is rendered
- Live CMS titles and URLs from the catalog

## Admin

- **Configure** — build the menu tree and order
- **Links** — manage custom link destinations

## Storefront

When Theme settings use **Custom menu (Main menu)**, the Classic theme loads this extension’s menu for the header. Default theme setting can remain category-based until you switch it.
